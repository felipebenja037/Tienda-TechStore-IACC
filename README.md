# TechStore Online - Programación Web II (Semana 8)

Este proyecto corresponde al desarrollo de una aplicación web de comercio electrónico realizada para la asignatura Programación Web II. Durante su desarrollo se aplicó un flujo de trabajo colaborativo utilizando Git y GitHub, implementando herramientas de control de versiones y colaboración propias de un entorno de desarrollo profesional.

La aplicación permite simular el funcionamiento de una tienda en línea mediante un catálogo de productos, carrito de compras, proceso de pago y confirmación de pedidos, manteniendo una estructura organizada y preparada para futuras mejoras.

## Características implementadas

### Estrategia de ramificación

Se implementó una estrategia de desarrollo basada en ramas, utilizando la rama `feature/gestion-pedidos` para desarrollar mejoras relacionadas con la gestión de pedidos sin afectar la rama principal (`main`). Esto permitió mantener una versión estable del proyecto durante el desarrollo.

### Pull Requests y revisión del código

Se utilizó un Pull Request para solicitar la integración de los cambios realizados en la rama de desarrollo hacia la rama principal. Este mecanismo permite revisar el código, incorporar observaciones y validar las modificaciones antes de su integración definitiva.

### Gestión de incidencias mediante GitHub Issues

Se creó un Issue para registrar una propuesta de mejora relacionada con la integración de una pasarela de pago, permitiendo documentar el problema, plantear una solución y facilitar el seguimiento de futuras implementaciones.

### Buenas prácticas de control de versiones

Durante el desarrollo del proyecto se aplicaron las siguientes prácticas:
- Uso de ramas para el desarrollo de nuevas funcionalidades.
- Commits con mensajes descriptivos.
- Publicación de cambios mediante Push al repositorio remoto.
- Revisión de cambios utilizando Pull Requests.
- Pruebas de funcionamiento antes de registrar cada modificación.
- Protección de la configuración de la base de datos evitando publicar credenciales.
