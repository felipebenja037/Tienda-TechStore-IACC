# TechStore Online

Aplicación web de comercio electrónico desarrollada como proyecto académico para la asignatura **Programación Web II** semana 8.

## Descripción

TechStore Online es una tienda virtual desarrollada con PHP, HTML, CSS y JavaScript, que simula el proceso de compra de productos tecnológicos. El proyecto fue construido aplicando buenas prácticas de desarrollo web y control de versiones mediante GitHub.

## Funcionalidades

- Visualización de catálogo de productos.
- Carrito de compras.
- Resumen de compra.
- Confirmación de pedidos.
- Gestión de pedidos mediante ramas de Git.
- Uso de Pull Requests e Issues para el trabajo colaborativo.

## Tecnologías utilizadas

- PHP
- HTML5
- CSS3
- JavaScript
- MySQL
- Git
- GitHub

## Estructura del proyecto

El proyecto se encuentra organizado en carpetas para facilitar su mantenimiento y escalabilidad, separando la lógica de negocio, recursos gráficos, estilos y scripts.

## Flujo de trabajo

Durante el desarrollo se aplicó el flujo de trabajo con Git y GitHub utilizando:
- Rama principal (`main`)
- Rama de desarrollo (`feature/gestion-pedidos`)
- Commits descriptivos
- Pull Requests
- Issues para el registro de mejoras
